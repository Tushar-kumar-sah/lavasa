# Cafe Lavassa — Botanical Garden Café & Artisan Bakery

A modern, luxury, fully responsive website for **Cafe Lavassa** (Lavassa Café & Bakery), located in Behala, Kolkata, West Bengal, India.

> *“Your Little Escape, One Cup at a Time.”*

---

## ✨ Key Features

* **Cinematic Hero:** Real illuminated storefront photography, warm botanical glow, and verified city badges.
* **The Lavassa Experience:** Editorial lifestyle section highlighting rattan lights, hanging plants, and cozy seating.
* **Signature Celebrations:** Spotlight on the famous *San Sebastián Burnt Basque Cheesecake* with warm Belgian chocolate drip and Spanish *Artisan Cortado*.
* **Interactive Menu:** Filter by category (*Coffee*, *Beverages*, *Savoury Baos*, *Pizza & Pasta*, *French Bakery & Desserts*), dietary filter (*Vegetarian* / *Non-Veg*), real-time search, and complete menu view modal with verified prices in ₹.
* **Photo Gallery & Lightbox:** Masonry photo gallery featuring authentic Cafe Lavassa photographs with an interactive modal lightbox.
* **Customer Reviews:** Real Google review testimonials with ratings and diner highlights.
* **Table Reservation Desk:** Validated booking form, instant WhatsApp booking desk, and direct telephone contact.
* **Visit Us & Dynamic Hours:** Embedded Google Maps, live "Open Now / Closed" calculator based on Kolkata time (10 AM – 10:30 PM), and transit directions.
* **Floating Mobile Actions:** Quick one-handed booking, WhatsApp chat, and phone dialer.

## 🛠️ Tech Stack

* **Framework:** React 19 + TypeScript
* **Styling:** Tailwind CSS (Custom Botanical & Coffee palette)
* **Icons:** Lucide React
* **Build Tool:** Vite 6
* **SEO:** Local SEO schema markup (`CafeOrCoffeeShop`), Open Graph, and Twitter metadata.

## 🚀 Getting Started

### Prerequisites

* Node.js (v18+)
* npm (v9+)

### Installation

```bash
# Clone the repository
git clone https://github.com/Tushar-kumar-sah/lavasa.git
cd lavasa

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will run locally at `http://localhost:5173`.

### Production Build

```bash
npm run build
npm run preview
```
